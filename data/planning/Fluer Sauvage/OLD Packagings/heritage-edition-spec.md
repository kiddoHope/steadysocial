- **Finish:** Soft-touch matte coating
- **Printing:** Full-color offset with spot UV on logo
- **QR Code:** Unique per certificate, links to verification page

#### Content Structure:
```markdown
FRONT:
  - Brand Logo (debossed)
  - "Certificate of Origin" title
  - "Heritage Collection" designation
  - Certificate Number: HE-001234
  - Limited Edition Notation: "/250"
  - QR Code with URL: https://fluersauvage.com/verify

  - Batch Information: "First Production Run, Batch #001"
```

## Quality Control Specifications

### Pre-Fill Inspection Checklist:

| Check | Pass Criteria | Reject Criteria |
|-------|---------------|-----------------|
| Glass Integrity | No visible cracks/chips under LED light | Any crack >1mm deep |
| Residue Inside Bottle | None (or minimal, removable) | Crystal buildup on walls |
| Cap Threads | Undamaged, smooth rotation | Stripped threads, cross-threading |
| Label Application Surface | Clean, dry, smooth | Stains, moisture, rough texture |
| External Scratches | Cosmetic only | Scratches near fill line |

### Fill Weight Verification:
- **50ml Target:** 18.5g ±0.5g (actual volume may vary by oil density)
- **30ml Target:** 11g ±0.4g
- **Recording Required:** Weigh bottle before fill (baseline), after fill, log variance >±1g for QA review

### Post-Fill Quality Checks:

| Check | Method | Acceptance Criteria |
|-------|--------|---------------------|
| Leak Test | 30-minute vertical hold | Zero leakage at seams or cap |
| Cap Torque | Digital torque wrench | Specified range (verify with supplier)
| Barcode/QR Scan | Mobile scanner app | 100% scanable, correct data displayed
| Label Adhesion | Water spray test (5 minutes) | No peeling >2mm after drying |
| Visual Inspection | Overhead lighting at 30° angle | No bubbles, spills, or misalignment |

### Batch Acceptance Criteria:
- **Pass Rate:** ≥95% of units meet all quality standards
- **Damaged Bottle Quarantine:** <3% threshold triggers batch review
- **Customer Complaint Target:** ≤0.5% return rate within first 60 days

## Packaging Assembly SOP

### Step 1: Quality Check (Pre-Fill)
```
Action:
  - Inspect each bottle under LED lighting (minimum 1000 lux)
  - Remove damaged bottles from heritage line immediately
  - Document rejection in batch log with photo attachment
  
Acceptance:
  - Log number of rejected units per hour
  - Quarantine >3% reject rate and notify QA supervisor
```

### Step 2: Label Preparation
```
Action:
  - Apply "Vintage Reserve" label (distinct from standard)
  - Affix authenticity seal if UV/heritage SKU requires it
  - Note production date and batch number on manifest
  
Acceptance:
  - Labels centered within ±2mm tolerance
  - No wrinkles, bubbles, or misalignment >1mm
```

### Step 3: Filling Station
```
Action:
  - Weigh bottle before fill (baseline: 0g)
  - Target fill weight: 18.5g for 50ml, 11g for 30ml
  - Record any variances >±1g in QC log
  - Monitor nozzle for drips/spills between fills
  
Acceptance:
  - Fill tolerance: ±0.5g acceptable, >1g flagged for review
  - Nozzle drip time <5 seconds maximum
```

### Step 4: Capping & Quality Control
```
Action:
  - Cap at specified torque (calibrated daily)
  - Final visual inspection (lighting ≥800 lux overhead)
  - Apply batch QR code if not pre-printed on label
  
Acceptance:
  - Cap height consistent across units (<1mm variance)
  - No sealant leakage onto exterior
  - QR codes readable at >3 inches distance
```

### Step 5: Documentation
```
Action:
  - Update inventory sheet (bottles → sold/unsold)
  - Record in production log with timestamp
  - Prepare shipping manifest by destination
  
Acceptance:
  - Inventory system updated within 2 hours of batch completion
  - Manifest matches physical count ±1% tolerance
```
